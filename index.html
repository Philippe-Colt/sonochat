Parametres

Telecharger l'application Android

Necessaire pour commander le PTT par port serie USB (Digirig Mobile, poste USB) depuis un telephone.

Envoye en tete de chaque message (obligatoire pour emettre). Lettres et chiffres.

Accuse de reception : demande au destinataire choisi a cote de votre indicatif. 99 = message en l'air, pour tous, sans accuse.

Fichier texte ou CSV : une ligne par station, indicatif court, indicatif long, puis (facultatif) type d'unite et echelon pour la carte, ex. PC;F4MTX;infanterie;section ou XY;F4XYZ;pompiers. Sans entree, l'indicatif court est affiche.

Reseau a plusieurs stations : 5e colonne = canal (frequence d'emission en Hz, 500-2500, au moins 50 Hz d'ecart ; 1400-2500 d'abord), 6e = creneau (1-98) des balises automatiques, ex. PC;F4MTX;infanterie;section;1400;1 ou XY;F4XYZ;;;1460;2 (colonne vide ou -). En-tete facultatif : #reseau;creneau=15;tour=12;version=3;date=2026-10-03 (creneau en s, tour = nombre de creneaux). Toutes les stations recoivent tous les canaux en meme temps.

Types : infanterie, motorisee, mecanisee, blinde, reco, artillerie, genie, sol-air, aviation, transmissions, nrbc, renseignement, police-militaire, sante, logistique, maintenance, transport, commandement, pompiers, samu, police, gendarmerie, secours (ou un code SIDC APP-6 de 15 car.). Echelons : equipe, groupe, section, compagnie, bataillon, regiment, brigade, division.

80%

Deconnecte

Avance : PTT ferme avant le son (temps de commutation du poste). Maintien : PTT garde apres la fin du son (latence audio).

Une trame FT8 (12,6 s), en l'air pour tous, sans accuse, position GPS au metre. Les autres stations la voient sur la carte, pas dans le fil.

Pour un cable VOX (Digirig VOX PTT) sur la prise casque : tonalite de 2000 Hz sur le canal droit pendant toute l'emission, FT8 sur le canal gauche seul. Les delais ci-dessus s'appliquent ; prevoir 150 a 200 ms d'avance.
